# 第二轮实验：采样温度与加入《彷徨》

日期：2026-11-10。目的：先观察采样参数，再比较增加同作者语料后的变化；本轮不设定流畅短句目标。

结论：更多训练文本改善了共同保留区段上的预测能力，过拟合出现得更晚，但没有带来明显的续写可读性提升。低温度反而出现大量重复，调温不能替代模型能力。

## 实验设计与可复现命令

先对原《呐喊》最佳模型做 temperature 0.3、0.5、0.8 对比，三类固定前缀（训练、验证、新组合）、种子 42、各生成 200 个 token。完整结果在 `runs/nahan-temperature/samples.json`，统一对比报告也包含同一实验。

随后准备《彷徨》11 篇小说，详见 [来源与处理](corpus-panghuang.md)。为控制词表变化，重新从随机初始化训练一对模型：

| 项目 | 共享词表对照组 | 混合组 |
| --- | --- | --- |
| 训练语料 | 《呐喊》 | 《呐喊》+《彷徨》 |
| 训练字符 | 61,832 | 128,480 |
| 词表 | 相同的 2,982 token，仅来自两书训练区段 | 相同 |
| 参数量 | 1,589,504 | 相同 |
| 网络与优化 | 4 层、128 维、4 头、上下文 256、批大小16、AdamW、学习率0.0003、种子42 | 相同 |
| 训练预算 | 2,000 步，819.2 万预测位置 | 相同 |

保留原模型，不直接给旧检查点扩词表或续训。这避免词表迁移与训练起点同时变化；两组重新训练的初始权重一致，程序确认三个验证面板的初始化评分完全相同。

混合组按可用窗口数采样，约 48% 来自《呐喊》，52% 来自《彷徨》。相同步数意味着混合组对每份文本重复次数更少，不能同时保持每篇曝光次数不变。

```sh
# 下载或复用11篇页面缓存，生成共享词表数据；已有非空输出目录会拒绝覆盖
uv run python -m micro_rsi.data.panghuang

# 两组均从随机初始化开始，使用独立目录
uv run micro-rsi train --config configs/pretrain/nahan-control.toml
uv run micro-rsi train --config configs/pretrain/nahan-panghuang.toml

# 独立加载三个实验的检查点，在共同区段评分并生成温度对比
uv run micro-rsi compare

# 直接试用本轮混合模型
uv run micro-rsi generate --checkpoint artifacts/checkpoints/nahan-panghuang/best.pt \
  --prompt '夜里，我一个人走在路上，' --temperature 0.8 --max-new-tokens 200
```

当前默认比较报告已存在，重跑时需指定新的 `compare --output runs/新目录/report.json`。训练与数据准备重跑也需使用新目录。配置和数据路径相对项目根目录。

## 共同验证区段上的 loss

独立进程分别遍历《呐喊》《彷徨》及两书合并的保留区段，窗口策略与前轮完整验收一致。两模型使用同一词表、相同文本和目标，因此本表可直接成对比较。包含未知字符目标，同时报告文件还记录只含已知目标的指标。

| 检查点 | 《呐喊》验证 loss | 《彷徨》验证 loss | 合并验证 loss |
| --- | --- | --- | --- |
| 对照组初始化（第0步） | 8.0402 | 8.0509 | 8.0458 |
| 对照组最佳（第700步） | 4.6763 | 5.4514 | 5.0785 |
| 对照组第2000步（第2000步） | 5.4340 | 6.5136 | 5.9941 |
| 混合组初始化（第0步） | 8.0402 | 8.0509 | 8.0458 |
| 混合组最佳（第1100步） | 4.5416 | 4.6347 | 4.5899 |
| 混合组第2000步（第2000步） | 4.6715 | 4.7753 | 4.7254 |

最佳检查点比较：混合组在《呐喊》loss 上改善约 0.135，在《彷徨》改善约 0.817，合并改善约 0.489。说明新增语料对未参与训练的区段预测有收益，并非仅换了更容易的验证集。

对照组最佳点由《呐喊》固定验证窗口选择；混合组最佳点由两书合并固定验证窗口选择。选择准则的文本范围不同，且最佳步数不同。上表同时列出相同第 2,000 步的结果，也能看到混合组较少过拟合，但单种子实验不能证明所有设置下均成立。

## 耗时与过拟合

- 对照组：总耗时 138.7 秒，更新耗时 123.1 秒，最佳第 700 步；其自身固定验证窗口 loss 为 4.6329，最终为 5.3916。
- 混合组：总耗时 140.1 秒，更新耗时 123.4 秒，最佳第 1100 步；其自身固定验证窗口 loss 为 4.5523，最终为 4.6852。

混合组最佳点从对照组第700步延后到第1100步，最终 loss 仍高于最佳点，说明增加约一倍文本缓解但未消除过拟合。两组自身固定窗口指标面对的验证文本不同，不能只比较 4.63 与 4.55 就作结论，主要证据是上一节共同区段评分。

## 产物、验证与限制

- 本地原件：`data/raw/panghuang-wikisource/`，含11个带修订号的API响应。
- 成对数据：`data/processed/nahan-control/`、`data/processed/nahan-panghuang/`。
- 检查点与日志：`artifacts/checkpoints/` 和 `runs/` 下对应同名目录；原《呐喊》产物完整保留。
- 独立对比记录：`runs/corpus-comparison/report.json`，包括初始/最佳/最终同区段评分，以及三模型、三种温度、三前缀的完整输出。
- 新增正文提取排除导航许可、数据保留原划分与共享词表、重复指标的行为测试；全套14项测试通过，代码与格式检查通过。
- 词表共享对照预先知道《彷徨》训练字符集合，但没有用验证文本建词表；更多细节见来源文档。
- 保留区段仍用于选择检查点，不是未参与开发的独立测试集。只有一个随机种子，样本只覆盖三个前缀，不能据此给出统计显著性或通用语言能力结论。
- 两来源引号和个别用字不同，新增语料还带有来源格式差异；模型训练步数相同，数据曝光分布变化，不能将效果归因于唯一因素。

本轮完成了计划中的采样与语料增量实验。下一步选择应以这份证据为基础；没有自动扩大模型、延长训练或引入新的流畅性目标。
