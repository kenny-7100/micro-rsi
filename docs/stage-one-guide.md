# 第一阶段实现导读

从命令到模型，建议按以下顺序阅读代码，并对照一次短跑输出。参数和初始设计见 [训练方案](stage-one-plan.md)，实际结果见 [实验记录](stage-one-results.md)。

## 1. 文本为什么要先切分

`src/micro_rsi/data/corpus.py` 从固定的 Gutenberg 文件提取 14 篇小说，去掉序言、尾注和排版空白，使用 OpenCC `t2s` 转为简体，在句末恢复换行。篇目作为独立文档，不拼接成跨篇窗口。

每篇前 90% 字符训练、末尾 10% 验证。先切分再构造窗口，保证训练标签和验证文本没有区段重叠。同一作品风格相近、重复短句仍可能出现在两边，所以本实验只是同一作品内的保留区段评估，不能代表跨作者、跨任务泛化。

## 2. 字符如何变成数字

`tokenization/character.py` 只扫描训练文本，排序字符形成稳定词表。0 号是 `<unk>`，其它 ID 对应一个字符。词表本身不包含语义，embedding 才是会被训练更新的参数。

验证中的未知字符映射为 0 并统计比例；生成前缀出现未知字符直接报错。生成时屏蔽 0 号，避免输出无意义的 `<unk>`。保存和加载始终使用同一映射；未来增加词表需要显式迁移模型。

## 3. 输入、标签和窗口

`data/windows.py` 对长度为 T+1 的连续片段分别取 `[:-1]` 和 `[1:]`：输入、标签形状都是 `[B,T]`。每个位置预测紧接其后的字符，而不是复制当前字符。

窗口随机采样按篇目可用起点数加权，不跨篇目边界。短于 T+1 的验证区段也可以保留：右侧输入补 0，标签补 -100，交叉熵忽略 -100。因果遮罩保证真实位置不会读取未来的补齐位置。长度不足 2 的区段不产生预测样本。

## 4. 模型如何使用前文

`models/transformer.py` 的流程是：

1. token embedding 与位置 embedding 相加，得到 `[B,T,C]`。
2. 每层先归一化，计算注意力，再加回残差。
3. Q、K、V 各为 `[B,H,T,D]`；Q 与 K 点积得到 `[B,H,T,T]` 的分数，除以 `sqrt(D)`。
4. 将未来位置分数设为负无穷，softmax 后未来位置权重为 0，再按权重读取 V。
5. 前馈网络在每个位置独立变换特征，仍保留残差。
6. 最后映射为 `[B,T,V]` 的词表分数 logits。

测试通过“修改后半段输入，前半段 logits 应保持完全相同”检查因果性。没有因果遮罩，模型训练时可以偷看下一个字符，loss 就失去验收意义。

## 5. loss 与参数更新

`training/runner.py` 将 logits 展平为 `[B*T,V]`，标签展平为 `[B*T]`。交叉熵内部执行 log-softmax，衡量正确字符的负对数概率，单位为自然对数；无需先给 logits 做 softmax。

AdamW 根据反向传播得到的梯度更新权重。梯度裁剪防止异常大更新，dropout 和权重衰减帮助缓解过拟合，但不保证消除它。训练 loss 是抽样窗口的表现，验证 loss 是另一组固定种子窗口的表现。

每次评估都切换 `eval()`、关闭梯度，并重设独立的窗口采样器。按非补齐标签总数汇总交叉熵；评估后恢复原模式，不干扰训练窗口随机流。这里的 loss 是固定窗口采样估计，不是完整验证集逐字符遍历。

## 6. 生成为什么一次一个 token

`inference/generation.py` 只取最后一个位置的 logits，除以 temperature，softmax 后采样一个 token，再把它追加到输入。新的 token 才会成为下一次预测的上下文。

训练时所有正确前缀已知，所以一轮前向能同时计算多个位置；生成时下一个 token 尚未产生，需要顺序推进。当前超过上下文长度就保留最近 T 个 token 并重新计算，未使用 KV cache。

采样用独立 CPU 随机生成器，便于比较相同采样种子；模型 logits 仍随设备和版本产生数值差异，因此不承诺跨设备完全一致。

## 7. 为什么单独加载很重要

检查点内含结构配置、词表和参数。推理命令不读取训练内存对象或原始语料。测试在新 Python 进程中执行 CLI 并比较输出，检查完整保存加载流程。

`initial.pt` 保存随机模型，`best.pt` 保存最低验证 loss，`last.pt` 保存最终状态。每个实验使用单独目录，拒绝覆盖；优化器和 PyTorch 随机状态随检查点保存，但当前没有恢复训练 CLI。

## 8. 如何判断结果

先比较同一固定验证窗口上的初始化与最佳 loss，再检查三类固定前缀的生成：训练片段、验证片段、新组合。生成质量应结合重复和原文复现检查，不能只挑一句看起来合理的内容。

首次模型只有百万级参数和约数万字训练文本，即使 loss 明显下降，仍可能只有局部句式与标点规律，无法稳定表达完整意思。加入《彷徨》前先保留本轮基线和数据版本。
