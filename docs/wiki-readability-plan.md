# 百万字符中文语料与模型尺寸对照

日期：2026-11-10。目标：准备数百万字符的现代中文训练文本，建立独立于 loss 的短续写可读性验收，再比较原尺寸网络和适度扩大网络。实际结果见 [本轮结果](wiki-readability-results.md)。

## 搜索与语料选择

选择 Wikimedia 在 Hugging Face 发布的 [wikimedia/wikipedia](https://huggingface.co/datasets/wikimedia/wikipedia)，中文配置 `20231101.zh`，它提供已去除大部分标记与参考文献的文章正文。训练数据未使用预训练模型生成或改写。

选择理由：发布方与来源明确；有开放许可说明；按文章保留 ID 和 URL；可一次下载 Parquet 批量分片，无需反复请求维基百科页面。百科体裁比文学作品更接近一般现代中文说明文，但包含专业名词、译名和抽取残留，不能称为逐字人工校对的“纯净语料”。本轮只做保守规则清洗并抽查。

没有采用需要逐页下载的站点，也没有下载整个中文维基百科。实际只取一个 126,796,358 字节的分片，约 121 MiB；批量文件下载一次成功，未触发限流或循环重试。

## 清洗、去重和划分

实现：`src/micro_rsi/data/wikipedia.py`。

- Unicode NFC 规范化，OpenCC t2s 繁转简。保留中文标点；避免 NFKC 将全角逗号变为 ASCII，导致旧前缀和阅读习惯不一致。
- 段落保留80～3,000字符、至少2个中文句末标点、汉字占比不低于65%；文章筛选后512～16,000字符。
- 排除列表、年表等标题，以及网址、模板、异常替代字符、明显重复字符等段落；保留自然段换行。
- 规范化全文与整段精确去重，出现已见重复段落即剔除整篇；未做语义或近似去重，不保证消除所有同源改写。
- 文章ID的 SHA-256 固定分配94%/3%/3%到训练、验证、测试，整篇隔离；按数据目标达到后停止。实际比例因文章长度和配额截取而不同。
- 词表只从训练数据建立，保留至少出现5次且在最高频6,000字符内的字符，另加未知字符 token。验证/测试不参与词表构建。
- 训练时只读取训练与验证文本；测试集在训练完成并冻结最佳检查点后评分，不参与检查点选择。

第一次清洗使用NFKC，发现中文标点会被转换，因此在正式训练前改为NFC并输出新目录 `wiki-zh-5m-v2`，旧数据不覆盖、也不与新指标混用。该版本是本轮正式数据。

最终词表4,789个token。训练与验证中的未知字符仍按同一未知token参与loss，生成屏蔽该token，前缀含未知字符明确拒绝。

抽查8篇文章可见多数句段为可读中文，但存在“（）”、外文译名缺失、个别语病等源抽取问题。该语料是过滤后的百科说明文，不是小说文体的延续；本轮不能把新loss与前轮鲁迅模型loss直接比较。

## 模型与预算

两组都从随机初始化开始，使用相同数据、词表、上下文、优化器、步数与训练窗口随机种子。

| 设置 | 当前尺寸 | 适度扩大 |
| --- | --- | --- |
| 层数 | 4 | 6 |
| embedding维度 | 128 | 256 |
| 注意力头 | 4 | 8 |
| 前馈维度 | 512 | 1,024 |
| 参数量 | 2,052,096 | 7,256,576 |
| 上下文长度 | 256 | 256 |
| dropout | 0.1 | 0.1 |
| batch size | 16 | 16 |
| AdamW学习率 | 0.0003 | 0.0003 |
| 权重衰减/梯度裁剪 | 0.01 / 1.0 | 相同 |
| 正式步数 | 6,000 | 6,000 |
| 预测位置数 | 24,576,000 | 相同 |

当前尺寸参数量比上一轮更大是因为字符词表扩大，隐藏层结构不变。两组按层数缩放残差输出投影的初始化标准差 `0.02/sqrt(2L)`，其余权重0.02。这与旧实验初始化细节不同，旧权重仍可加载；本轮研究的是相同数据和训练配置下的尺寸对照，不宣称只有单个数值发生变化。

有效100步短跑：当前尺寸约0.069秒/步，扩大约0.191秒/步，未发现非有限loss或显存不足。扩大模型短跑学习率0.0002，正式两组统一为0.0003，所以短跑loss不是正式学习率对比的证据。

固定验证窗口每500步评分，按验证loss选best.pt，不按生成观感挑检查点。6000步是本轮观察预算，不保证足够收敛或达到可读标准；同token预算不是同算力预算，扩大网络更耗时。

## 短文本可读性验收

训练前固定 `configs/evaluation/readability.json`：8个说明文前缀、3个采样种子、每份80个新字符、temperature0.7。每模型24份，共48份，随机打乱顺序并隐藏模型名称。

逐份按0～2分评估词语搭配、句子可理解性、前后衔接、机械重复。单份通过要求词语、句子、重复三项都不低于1；衔接另报。模型最低门槛为至少18/24份通过且句子平均分不低于1。该门槛是预先约定的工程标准，不是学术通用标准。

由Agent逐条审阅并记录理由；原始样本、盲化视图、分数和解盲映射分别留存。这是主观代理评分，不等于独立人类评测，用户可用相同样本复核。自动指标与loss只做辅助，不代替可读性评分。固定前缀用于本轮最终报告，不用其输出反复挑采样设置。

## 复现命令

下列为本轮 v2 历史命令。当前清洗器已经修复词间空格和空字段处理，默认输出 v3；重新运行不能逐字重建 v2，不应把新版处理结果标为 v2。历史训练使用的数据 SHA256 见各运行目录，旧数据保持冻结。当前处理版本与结果见 [诊断记录](training-diagnosis.md)。

在项目根目录执行。数据、运行与检查点目录拒绝覆盖，重跑请指定新路径。原始文件需要先按上方固定地址下载到默认路径。

```sh
uv sync
uv run python -m micro_rsi.data.wikipedia --output data/processed/wiki-zh-5m-v2
uv run micro-rsi train --config configs/pretrain/wiki_zh_current.toml
uv run micro-rsi train --config configs/pretrain/wiki_zh_medium.toml
uv run python -m micro_rsi.evaluation.scale_comparison
uv run micro-rsi readability collect
# 审阅blind-review.json，逐项填写review.json后汇总
uv run micro-rsi readability score
```

`readability`生成的模型权重不依赖数据原件即可独立推理；完整loss和测试评分仍需处理后的对应文本。原始语料、处理数据、检查点与完整日志按项目约定只保存在本地。
